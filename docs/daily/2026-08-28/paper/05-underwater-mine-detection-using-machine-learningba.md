## 核心内容

水下水雷检测对海军安全和航道保障至关重要。传统声呐信号分类依赖人工特征提取和浅层分类器，难以适应复杂水下环境。本文研究基于机器学习的声呐信号分类方法，用于水下水雷自动检测，旨在提高检测准确率与鲁棒性，减少人工判读负担。

## 关键技术与数据

方法涵盖声呐信号预处理、特征提取与机器学习分类器设计。预处理包括去噪与归一化；特征提取涉及时域、频域及时频域特征；分类器包括支持向量机、随机森林等经典机器学习算法。实验数据为实测或仿真的水雷与杂波声呐回波信号，用于训练与评估分类性能。

## 结果与结论

实验结果显示基于机器学习的方法在水雷检测中取得了较高的分类准确率，优于传统阈值检测方法。研究验证了机器学习在声呐信号分类中的有效性，为水下水雷自动检测提供了可行方案，但性能仍受限于特征工程的质量与训练数据的代表性。
