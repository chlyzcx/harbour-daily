## 核心内容

声呐图像目标检测受水下复杂背景、阴影干扰与低对比度影响，传统视觉特征方法难以有效区分目标与海底杂波。该论文提出一种声学特征引导的声呐目标检测方法，通过阴影感知注意力与对比度响应增强机制，提升前视声呐与侧扫声呐图像中目标的检测精度与鲁棒性。

## 关键技术与数据

方法构建了阴影感知注意力模块，利用声呐图像中目标阴影的几何特征引导网络关注有效区域；对比度响应增强模块通过局部对比度拉伸与频域滤波提升目标与背景的区分度。网络基于CNN检测框架，在声呐图像数据集（如SCTD、Marine Debris）上进行训练与评估，指标包括mAP与F1-score。

## 结果与结论

实验表明，所提方法在声呐目标检测任务中mAP较基线提升约6-8%，对沉船、礁石与人工目标等类别的检测精度显著提高。阴影感知与对比度增强有效抑制了海底杂波干扰，验证了声学特征引导在声呐图像理解中的有效性，为水下自主探测与目标识别提供了技术支撑。
