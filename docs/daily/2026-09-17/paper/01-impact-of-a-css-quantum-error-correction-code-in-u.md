## 核心内容

针对水下量子密钥分发（QKD）中光子损耗与环境噪声导致性能退化的问题，本文研究两种四量子比特Calderbank-Shor-Steane（CSS）量子纠错码（QECC）在垂直水下通信BB84协议中的补偿效果。作者建立综合随机信道模型，评估QECC对擦除与噪声的抑制能力，旨在探索水下量子通信的可行性。

## 关键技术与数据

采用BB84协议结合两种四量子比特CSS量子纠错码；构建包含光子擦除、环境噪声的随机信道模型；通过数值仿真分析误码率、密钥生成率等指标，对比有无QECC时的系统性能。

## 结果与结论

结果表明，CSS量子纠错码能有效降低水下QKD的误码率并提升密钥生成率，但受限于信道损耗，纠错能力存在阈值。研究为水下量子通信的纠错编码设计提供了理论依据，指出需结合信道特性优化码型以提升实用化水平。
