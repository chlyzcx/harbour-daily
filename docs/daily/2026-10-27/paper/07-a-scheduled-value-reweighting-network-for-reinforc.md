## 核心内容

本文针对障碍密集海洋环境中多自主水下航行器（AUV）协同追捕控制问题，解决部分可观测下的协同决策、环境障碍扰动及训练效率低等挑战。论文提出一种调度值重加权网络增强的多智能体深度确定性策略梯度方法（SVRN-MADDPG），用于提升多AUV协同追捕的学习效率与控制性能。

## 关键技术与数据

提出SVRN-MADDPG算法，在多智能体深度确定性策略梯度框架中引入调度值重加权网络（Scheduled Value Reweighting Network），以改善值函数学习与训练效率。方法面向部分可观测条件下的协同决策，处理障碍密集环境中的避障与追捕任务，通过值重加权调度机制缓解稀疏奖励与训练不稳定问题。

## 结果与结论

SVRN-MADDPG在障碍密集环境的多AUV协同追捕任务中提升了训练效率与控制性能，增强了部分可观测条件下的协同决策能力。研究为多AUV强化学习协同控制提供了改进算法，创新点在于将调度值重加权机制引入MADDPG以应对障碍密集环境下的训练效率与协同决策难题。
