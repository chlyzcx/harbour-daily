本文提出SAST-SDNet，一个用于侧扫声呐图像自适应增强与目标检测的自动化框架。侧扫声呐图像存在噪声强、对比度低、目标特征不明显等问题，影响目标检测性能。该框架旨在通过自适应增强与检测网络的联合设计，实现端到端的侧扫声呐图像目标检测。摘要未提供，具体研究背景和目标基于标题推断。
